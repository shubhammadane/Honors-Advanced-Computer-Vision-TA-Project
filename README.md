# Color Detection and Object Tracking

## Project Description
This project is a real-time Color Detection and Object Tracking system developed using Python and OpenCV.  
The application detects selected colors through a webcam and tracks the object by drawing a bounding box around it.

The project uses HSV (Hue, Saturation, Value) color space for accurate color detection and provides a simple graphical user interface using Tkinter.

---

# Features

- Real-time webcam access
- Multiple color detection
- Object tracking using bounding box
- HSV color filtering
- Adjustable sensitivity
- Detection timer
- Simple GUI interface
- Live tracking status

---

# Supported Colors

- Red
- Green
- Blue
- Yellow
- Orange
- Purple
- Pink
- White
- Black
- Gray

---

# Technologies Used

- Python
- OpenCV
- NumPy
